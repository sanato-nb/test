좀보이드 PNG 이미지 검수기 v8

변경 사항:
- 카드에 '① 정체' 입력칸과 '② 속성' 입력칸을 각각 표시합니다.
- 정체는 물체 이름/무엇인지, 속성은 형태/색상/구조/기능을 적습니다.
- 재질 복수 선택, 개별 확인 상태, 판정 근거 메모는 그대로 유지합니다.
- 검수 결과 전체 CSV에 name과 attributes가 분리되어 기록됩니다.
- 정체명이 없는 경우 새 '개별 정체 확인' 선택을 막습니다.
- 기존 v6/v7 기록과 IndexedDB 저장소를 유지합니다.

실행:
1. ZIP을 압축 해제합니다.
2. PZ_PNG_Tileset_Reviewer_v8.html 을 Chrome/Edge로 엽니다.
3. PNG 폴더 전체 선택으로 파일들을 등록합니다.
4. 목록에서 원하는 PNG의 '검수 열기'를 누릅니다.
5. '① 정체'와 '② 속성'을 별도로 적고 재질·검수 상태 등을 확인합니다.
6. 중간 저장 JSON 또는 전체 통합 검수 ZIP으로 기록을 백업합니다.

주의:
이 소프트웨어 ZIP에는 원본 PNG가 포함되지 않습니다.
브라우저 저장 위치(file://와 채팅 앱)는 다를 수 있으므로 기존 검수 기록이 나타나지 않으면 v6/v7 전체 중간 백업 JSON을 불러오세요.
PNG 이미지 격자 번호는 공식 Local ID가 확정된 경우에만 대응을 인정해야 합니다.
