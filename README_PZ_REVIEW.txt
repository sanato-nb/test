PZ PNG tileset review v6

1. Extract the downloaded ZIP.
2. Open PZ_PNG_Tileset_Reviewer_v6.html in Chrome or Edge.
3. Select all PNGs or their folder.
4. Click one PNG to review its tiles in cards.
5. Review progress is saved per PNG. Export JSON regularly.
6. The final review ZIP combines the per-tile CSV, PNG summary CSV, and JSON backup.

Source PNGs are not included in this software ZIP. Browser security requires reselecting source PNGs in a new session; previous reviews reconnect by name and file size.
